**Directory:** `agents/`

**Version:** 1.0.0

**Status:** Active

# Purpose

The `agents` directory contains the autonomous execution agents of the Oryxus Brand Engine.

Unlike Skills, which contain knowledge, or Prompts, which define execution instructions, Agents are responsible for coordinating complete workflows.

An Agent behaves like a senior specialist capable of planning work, activating the correct resources, validating quality, and producing production-ready deliverables.

---

# Agent Philosophy

Every agent should think like an experienced consultant.

An agent does not replace expertise.

Instead, it orchestrates expertise by selecting the correct Skills, Prompts, Frameworks, Templates, and Standards for the current task.

Agents should always prioritize:

- Accuracy
- Consistency
- Scalability
- Maintainability
- Business Value

---

# Architecture

Every agent follows the same execution model.

```
Client Request

↓

Understand Objective

↓

Collect Missing Information

↓

Load Skills

↓

Load Frameworks

↓

↓

Execute Workflow

↓

↓

```
