**Directory:** `prompts/`

**Version:** 1.0.0

**Status:** Active

---

# Purpose

The `prompts` directory contains the execution prompts that orchestrate the Oryxus Brand Engine.

Unlike the Skills Library, which stores domain expertise, prompts define how that expertise is activated to complete real client work.

A prompt is an execution layer.

It receives a business objective, activates the required skills, follows the Oryxus methodology, and produces structured, production-ready outputs.

---

# Prompt Philosophy

Prompts should never replace expertise.

They should coordinate expertise.

Every prompt acts like a Project Manager that assembles the right specialists, follows the correct workflow, and delivers consistent results.

Knowledge belongs inside **Skills**.

Execution belongs inside **Prompts**.

# Prompt Principles

Every prompt should:

- Follow the Oryxus methodology.
- Activate only the required skills.
- Produce structured documentation.
- Follow repository standards.
- Never skip research.
- Prioritize quality over speed.
- Remain reusable across industries.
