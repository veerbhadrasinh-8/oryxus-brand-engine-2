# Purpose

The `frameworks` directory contains the standardized methodologies used throughout the Oryxus Brand Engine.

A framework is a repeatable decision-making system.

Unlike Skills, which define expertise, or Agents, which coordinate execution, Frameworks define **how** work should be approached, evaluated, and completed.

Every project executed by Oryxus should follow these frameworks to ensure consistent quality, predictable outcomes, and scalable delivery.

---

# Framework Philosophy

Frameworks exist to eliminate guesswork.

They provide structured thinking that transforms complex business problems into repeatable processes.

Every framework should be:

- Practical
- Actionable
- Research-driven
- Business-focused
- User-centered
- Scalable
- Technology-agnostic

Frameworks should guide decisions—not replace critical thinking.
