**Status:** Active

# Purpose

The `skills` directory contains the specialized knowledge modules that power the Oryxus Brand Engine.

Each skill represents a senior-level domain expert with clearly defined responsibilities, methodologies, standards, workflows, and decision frameworks.

Unlike prompts that generate text, skills define **how an expert thinks, evaluates problems, makes decisions, and produces consistent outcomes**.

Every AI agent, workflow, playbook, and future Oryxus platform should rely on these skills as reusable knowledge modules.

---

# Why Skills Exist

Modern AI is capable of performing many different tasks.

However, high-quality results require expertise.

The purpose of the Skills Library is to provide that expertise in a structured, reusable form.

Instead of asking AI to "design a website," the Brand Engine activates multiple specialist skills that collaborate to produce professional outcomes.

This approach increases:

- Quality
- Consistency
- Accuracy
- Reusability
- Scalability

---

# Philosophy

Every skill should behave like a senior professional rather than a prompt.

A skill should define:

- How to think
- How to analyze
- How to prioritize
- How to evaluate
- How to make decisions
- How to deliver outputs

The goal is to replicate professional expertise—not simply generate content.
