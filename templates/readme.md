# ORYXUS TEMPLATES

**Directory:** `templates/`

**Version:** 1.0.0

**Status:** Active

---

# Purpose

The `templates` directory contains standardized document templates used throughout the Oryxus Brand Engine.

Templates ensure that every deliverable follows the same structure, quality standards, and documentation style regardless of the project, client, or team member producing it.

A template is not the final deliverable.

It is a reusable blueprint that accelerates execution while maintaining consistency.

---

# Objectives

The Templates module aims to:

- Standardize project documentation.
- Reduce repetitive work.
- Improve consistency across projects.
- Simplify collaboration.
- Accelerate project execution.
- Maintain professional deliverables.
- Support AI-assisted workflows.
- Improve long-term maintainability.

Every document generated by Oryxus should begin from an approved template.

# Template Standards

Every template should contain:

- Executive Summary
- Objectives
- Scope
- Required Inputs
- Documentation Sections
- Deliverables
- Review Checklist
- Approval Section
- Version History

Each template should follow the same documentation style used throughout the repository.

---

# Naming Convention

Templates should use:

```
<Deliverable_Name>_Template.md
```

Examples:

- `Research_Report_Template.md`
- `Website_PRD_Template.md`
- `Audit_Template.md`

Maintain consistent naming across the repository.

---

# Version Control

Whenever a template changes:

- Increment the version.
- Record the update in the changelog.
- Preserve backward compatibility where practical.
- Document major structural revisions.

Templates should evolve without breaking established workflows.

---

# Quality Standards

Every template should be:

- Clear
- Consistent
- Comprehensive
- Practical
- Business-focused
- Easy to complete
- Easy to review
- Ready for client delivery

Avoid unnecessary complexity or duplicated sections.

---

# Final Principle

Templates transform expertise into repeatable execution.

The Templates module exists to ensure every Oryxus deliverable is produced with the same level of structure, professionalism, and quality—regardless of who creates it.
